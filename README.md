# 途经 · Travel Footprints

一个纯前端旅行足迹小网站。打开 `index.html` 即可使用；新增的足迹保存在当前浏览器的 LocalStorage 中。首次打开为空白地图，不会加载示例足迹。

## 使用

- 点击右上角“添加足迹”，先在“目的地”中创建城市或国家，再在“交通段”中选择两个已保存目的地并记录一种交通方式。
- 同一行程可拥有任意多个目的地。转机、换乘或改乘其他方式时，分别添加下一条交通段；飞行与铁路里程会独立累计。
- 在地图顶部切换“足迹总览 / 航班航迹 / 铁路图”，可拖动缩放并查看路线分段。
- “随机一站”会带你回到任意一段已收藏的旅程。

底图、国家边界和照片均需联网加载。里程为坐标之间的球面距离估算值，不等同于航班或铁路的实际运营里程。
