# Travel-Footprints / 途经

记录旅行足迹的个人地图应用。

一个纯前端旅行足迹小网站。打开 `index.html` 即可使用；新增的足迹保存在当前浏览器的本地数据库中。首次打开为空白地图，不会加载示例足迹。

## 使用

- 点击右上角“添加足迹”，先在“目的地”中创建城市或国家，再逐段记录交通方式。
- 同一行程可拥有任意多个目的地。转机、换乘或改乘其他方式时，分别添加下一条交通段；飞行、铁路、汽车和轮船里程会独立累计。
- 在地图顶部切换足迹总览、航班航迹、铁路图、轮船航迹或汽车路线；可进一步切换 2D 与 3D 地球视图。
- “随机一站”会带你回到任意一段已收藏的旅程。

底图、国家边界和照片均需联网加载。里程为坐标之间的球面距离估算值，不等同于实际运营里程。
